设置 GitHub Token

用于将文件上传到 GitHub 仓库，通过 jsDelivr CDN 永久访问。Token 仅保存在本地浏览器中。

如何获取 Token（一次性操作）：
1. 打开 GitHub Token 创建页面
2. Token name: 填写任意名称（如 file-upload）
3. Resource owner: 选择 liuchaochaoer
4. Repository access: Only select repositories → file-storage
5. Permissions → Repository permissions → Contents: Read and write
6. Expiration: 建议选择 1 year 或更长
7. 点击 Generate token，复制生成的 Token 粘贴到上方
